## Resumo dos Conceitos Praticados

Durante a realização dos desafios, pude colocar em prática conhecimentos de HTML e CSS e entender melhor como funciona a criação e a estilização de páginas web. As atividades ajudaram a desenvolver minha lógica e a melhorar minha familiaridade com as ferramentas utilizadas.

Também tive algumas dificuldades durante os exercícios, principalmente na organização dos elementos e na utilização correta de algumas propriedades. Porém, com a prática, consegui compreender melhor os conceitos e aplicar o que foi aprendido de forma mais eficiente.
